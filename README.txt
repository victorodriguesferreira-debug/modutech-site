SITE MODUTECH - INSTRUÇÕES WINDOWS

1. Extraia o ZIP.
2. Abra o CMD na pasta modutech_site.
3. Execute: py -m pip install -r requirements.txt
4. Execute: py app.py
5. Abra: http://127.0.0.1:5000

O formulário abre o WhatsApp com mensagem pronta. Não salva pedidos em banco de dados.
O site só estará acessível na internet após publicação em uma hospedagem.
